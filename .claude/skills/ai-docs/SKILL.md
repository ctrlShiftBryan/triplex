# ai-docs

Generated docs live on the `ai-docs` branch, served at https://ctrlshiftbryan.github.io/triplex (GitHub Pages, readable by anyone on the internet). Code branches carry code. Publish without asking: writing the doc is the request. Make a claude.ai Artifact only when someone asks for one by name.

## 1. Choose the path

`ai-docs/<type>/<YYYY-MM-DD>-<slug>.<html|md>` at the repo root (this worktree). The folder is gitignored. Date = today; slug = lowercase words joined by `-`.

| type | holds |
| --- | --- |
| `plans` | implementation plans, proposals, design docs, decisions |
| `incidents` | outage timelines, root causes, postmortems |
| `investigations` | bug diagnoses, data checks, log triage, troubleshooting |
| `research` | vendor, API and approach comparisons |
| `explainers` | how a system, feature or change works; testing guides |
| `prototypes` | throwaway UI prototypes (`<slug>.prototype.html`) |

Format: HTML for anything people read in a browser; Markdown for plans and notes.

**Revising an existing doc:** pull the current version to the same staged path, edit it, and publish to the same path (links stay stable; git history keeps old versions):

```bash
git fetch origin ai-docs && mkdir -p ai-docs/<type> && git show origin/ai-docs:<type>/<file> > ai-docs/<type>/<file>
```

## 2. Write it

- **HTML:** one self-contained file (inline CSS/JS, images as data URIs, no network calls). Give it a short `<title>` and a one-sentence `<meta name="description">`; the index lists both.
- **Markdown:** start with front matter carrying `title:` and `description:`.
- **Secrets:** Anyone on the internet can read ai-docs. Name the secret store entry or env var instead of pasting a value; mask passwords in connection strings as `<password>`.

## 3. Publish

```bash
pnpm ai-docs:publish ai-docs/<type>/<file> [more files...]
```

The script scans for secrets, pushes from a throwaway worktree (retrying if a teammate pushed first), rebuilds `index.html`, opens the first HTML doc locally, and deletes the staged copy. `--keep`, `--no-open`, `--rm <branch-path>` (delete a doc) and `--allow-secrets` are in `--help`.

When the secret scan matches, redact and rerun. Use `--allow-secrets` only after checking every hit is a known non-secret.

Done when the script prints the URL. Reply with that URL. HTML links go to Pages and Markdown to GitHub's rendered view; Pages goes live 1–2 minutes after the push.
